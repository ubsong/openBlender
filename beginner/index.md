# 블렌더 입문

블렌더를 처음 켜 본 사람이 **첫 렌더 이미지를 뽑고, 간단한 애니메이션까지 만들어 보는 것**을 목표로 한 입문 잡지예요. 설치부터 시작하고, 전문 용어는 처음 나올 때 풀어서 설명해요.

## 이렇게 읽으면 좋아요

글은 앞에서부터 차례로 읽도록 짰어요. 각 글은 10분 안에 따라 할 수 있는 분량이고, 블렌더를 켜 놓고 직접 눌러 보며 읽는 걸 추천해요.

| 묶음 | 다루는 내용 |
|---|---|
| 시작하기 | 설치, 화면 구성, 화면 돌려 보는 법 |
| 모델링 | 모양 만들기, 편집 모드, 간단한 컵 만들기 |
| 재질과 렌더 | 색과 질감, 조명과 카메라, 이미지로 뽑기 |
| 움직이기 | 키프레임으로 움직임 만들기 |

## 버전 표시를 꼭 봐 주세요

블렌더는 몇 달마다 새 버전이 나오고, 버전마다 메뉴 이름이나 단축키가 조금씩 바뀌어요. 그래서 모든 글 맨 위에 **어느 버전에서 확인했는지**와 **마지막으로 고친 날**을 적어 둬요. 읽고 있는 글이 최신 버전보다 오래된 기준이면 안내가 자동으로 나타나요.

::: tip 단축키는 이렇게 표시해요
<kbd>Shift</kbd> + <kbd>A</kbd>처럼 적은 건 두 키를 함께 누르라는 뜻이에요. 단축키는 **마우스 커서가 올라가 있는 영역**에서 동작해요.
:::

## 준비물

- 블렌더를 돌릴 수 있는 컴퓨터 (Windows, macOS, Linux 모두 가능)
- 가운데 버튼(휠 클릭)이 있는 마우스를 권해요. 없어도 방법이 있으니 다음 글에서 알려드릴게요.
- 숫자 키패드가 없는 노트북도 괜찮아요.

준비됐다면 [설치와 첫 실행](/beginner/01-start/01-install)부터 시작해요.
