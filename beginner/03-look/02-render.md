# 조명, 카메라, 렌더링

3D 장면을 사진 한 장으로 뽑아내는 과정을 **렌더링**이라고 해요. 모양과 재질이 준비됐다면 남은 건 **조명, 카메라, 렌더 엔진 선택**이에요.

## 조명 다루기

<kbd>Shift</kbd> + <kbd>A</kbd> → **Light**에서 조명을 추가할 수 있어요.

| 종류 | 특징 |
|---|---|
| Point | 전구처럼 한 점에서 사방으로 빛나요 |
| Sun | 해처럼 먼 곳에서 평행하게 비춰요. 위치보다 *방향*이 중요해요 |
| Spot | 무대 조명처럼 원뿔 모양으로 비춰요 |
| Area | 사각형 면에서 부드럽게 빛나요. 사진 스튜디오 조명 느낌이에요 |

조명을 선택하고 프로퍼티 창의 전구 모양 탭에서 **Power**(세기)와 색을 바꿀 수 있어요. 제품 사진 같은 장면에는 Area 조명 하나로 시작하면 무난해요.

## 카메라 맞추기

렌더 결과는 **카메라가 보는 화면**이에요.

1. 3D 뷰포트에서 원하는 각도로 화면을 돌려 놔요.
2. 메뉴의 <kbd>View</kbd> → **Align View** → **Align Active Camera to View**를 선택해요. (단축키는 <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Numpad 0</kbd>)
3. <kbd>Numpad 0</kbd>을 눌러 카메라 화면으로 들어가 확인해요.

## 렌더 엔진 고르기

프로퍼티 창의 **Render** 탭에서 **Render Engine**을 고를 수 있어요.

| 엔진 | 특징 | 이럴 때 |
|---|---|---|
| **EEVEE** | 실시간에 가까운 빠른 렌더 | 빨리 결과를 보고 싶을 때, 애니메이션 |
| **Cycles** | 빛의 움직임을 계산하는 사실적인 렌더, 시간이 더 걸려요 | 사진처럼 정교한 결과가 필요할 때 |

둘 다 같은 장면을 렌더할 수 있으니 처음에는 EEVEE로 시작해 보세요. Cycles는 **Sampling** 값이 높을수록 깨끗하지만 오래 걸려요. 처음 테스트할 때는 낮춰 두고, 마지막에만 올리세요.

## 이미지로 뽑기

1. <kbd>F12</kbd>를 누르면 현재 카메라 화면이 렌더돼요.
2. 렌더 창에서 <kbd>Image</kbd> → **Save As**로 저장해요. (<kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd>)
3. 렌더 창을 닫으려면 <kbd>Esc</kbd>를 눌러요.

이미지 크기는 프로퍼티 창의 **Output** 탭에서 **Resolution X / Y**로 정해요.

::: warning 렌더가 너무 느려요
Cycles에서 샘플 수를 낮추고, 해상도 비율(Resolution %)을 50%로 줄여서 먼저 테스트해 보세요. 그래픽 카드를 쓰도록 설정하는 방법은 <kbd>Edit</kbd> → <kbd>Preferences</kbd> → **System**에서 확인할 수 있어요.
:::
