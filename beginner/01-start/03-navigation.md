# 화면 조작과 선택

3D 작업의 절반은 **원하는 각도로 화면을 돌려 보는 일**이에요. 마우스 조작부터 손에 익혀 봐요.

## 마우스로 화면 움직이기

3D 뷰포트 위에 커서를 올리고 해 보세요.

| 하고 싶은 일 | 방법 |
|---|---|
| 돌려 보기 (Orbit) | 가운데 버튼을 누른 채 끌기 |
| 옮기기 (Pan) | <kbd>Shift</kbd> + 가운데 버튼 끌기 |
| 확대 / 축소 | 마우스 휠 굴리기 |

### 가운데 버튼이 없다면

<kbd>Edit</kbd> → <kbd>Preferences</kbd> → **Input**에서 **Emulate 3 Button Mouse**를 켜면 <kbd>Alt</kbd> + 왼쪽 버튼으로 돌려 볼 수 있어요. 숫자 키패드가 없는 노트북이라면 같은 화면의 **Emulate Numpad**를 켜세요. 키보드 윗줄의 숫자가 키패드 숫자 역할을 해요.

## 정해진 방향으로 보기

3D 뷰포트 오른쪽 위의 **축 모양 아이콘**(기즈모)에서 X, Y, Z 동그라미를 누르면 정면, 측면, 윗면으로 바로 이동해요. 키패드가 있다면 이 키들도 써 보세요.

- <kbd>Numpad 1</kbd> 정면 · <kbd>Numpad 3</kbd> 오른쪽 · <kbd>Numpad 7</kbd> 위
- <kbd>Numpad 0</kbd> 카메라가 보는 화면
- <kbd>Numpad 5</kbd> 원근 / 직교 전환
- <kbd>Numpad .</kbd> 선택한 물체로 화면 맞추기

## 보여 주는 방식 바꾸기

<kbd>Z</kbd>를 누르면 보기 방식을 고르는 둥근 메뉴가 열려요.

- **Wireframe**: 뼈대 선만 보기
- **Solid**: 기본 모드. 빠르게 모양을 만들 때 써요
- **Material Preview**: 재질과 조명이 반영된 미리보기
- **Rendered**: 실제 렌더 결과에 가깝게 보기

## 선택하기

- 물체를 **왼쪽 클릭**하면 선택돼요. 선택된 물체는 주황색 외곽선으로 표시돼요.
- <kbd>Shift</kbd> + 클릭으로 여러 개를 선택하거나 선택에서 뺄 수 있어요.
- <kbd>A</kbd>는 전체 선택, <kbd>Alt</kbd> + <kbd>A</kbd>는 선택 해제예요.
- <kbd>B</kbd>를 누르고 끌면 상자 모양으로 영역을 선택해요.

::: tip 실수해도 괜찮아요
<kbd>Ctrl</kbd> + <kbd>Z</kbd>로 되돌릴 수 있어요. 새로운 키를 눌러 보며 익힐 때는 마음껏 눌러 보고 되돌리세요.
:::
