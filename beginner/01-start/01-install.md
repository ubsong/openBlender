# 설치와 첫 실행

블렌더는 무료로 받아서 쓸 수 있는 오픈소스 프로그램이에요. 회원가입이나 결제 없이 공식 사이트에서 바로 받을 수 있어요.

## 어디서 받나요

공식 사이트 [blender.org](https://www.blender.org/download/)의 다운로드 페이지에서 내 운영체제에 맞는 파일을 받아요. Windows, macOS, Linux를 모두 지원해요. 같은 프로그램이 Steam과 Microsoft Store에도 올라와 있어서 그쪽이 편하면 거기서 받아도 돼요.

::: warning 출처를 확인하세요
블렌더를 받을 때는 공식 사이트나 공식 스토어 페이지인지 꼭 확인하세요. 검색 결과 광고에 비슷한 이름의 사이트가 섞여 있을 수 있어요.
:::

## 어느 버전을 받을까요

| 선택 | 이럴 때 |
|---|---|
| 최신 안정 버전 | 새 기능을 바로 써 보고 싶을 때. 몇 달마다 새 버전이 나와요 |
| LTS 버전 | 오래 안정적으로 쓰고 싶을 때. LTS는 정해진 기간 동안 버그 수정만 이어지고 기능은 바뀌지 않아요 |

입문 단계에서는 둘 중 아무거나 괜찮아요. 이 잡지는 **5.2 LTS**를 기준으로 쓰고 있어요. 5.2 LTS는 2028년 7월까지 지원된다고 공식 사이트에 안내되어 있어요.

## 설치하기

- **Windows**: 설치 파일을 실행하고 안내를 따라가면 돼요. 압축 파일(zip) 버전은 풀기만 하면 바로 실행돼요.
- **macOS**: 받은 `.dmg` 파일을 열어서 Blender를 응용 프로그램 폴더로 끌어다 놓아요.
- **Linux**: 압축 파일을 풀고 안에 있는 실행 파일을 열어요.

## 첫 실행

처음 실행하면 시작 화면이 뜨고, 여기서 언어와 마우스 선택 방식 같은 기본 설정을 고를 수 있어요. 선택 방식은 **왼쪽 클릭으로 선택**이 기본이고, 이 잡지도 그 기준으로 설명해요.

### 한국어로 바꾸기

메뉴에서 <kbd>Edit</kbd> → <kbd>Preferences</kbd>를 열고, **Interface** → **Translation**에서 **Language**를 한국어로 바꾸면 돼요. 번역할 대상(인터페이스, 툴팁, 새로 만드는 데이터 이름)을 항목별로 켜고 끌 수 있어요.

::: tip 영어 이름도 알아 두세요
인터넷에 있는 튜토리얼은 대부분 영어 메뉴 이름으로 설명해요. 한국어로 쓰더라도 이 잡지에서 단축키와 영어 메뉴 이름을 같이 적어 둔 이유예요.
:::

## 저장하는 습관

<kbd>Ctrl</kbd> + <kbd>S</kbd>로 저장하면 `.blend` 파일이 만들어져요. 블렌더에도 자동 저장이 있지만 임시 폴더에 저장되는 복구용이라서, 작업 중에는 직접 자주 저장하는 게 안전해요. 갑자기 꺼졌다면 <kbd>File</kbd> → <kbd>Recover</kbd> → <kbd>Auto Save</kbd>에서 불러올 수 있어요.
