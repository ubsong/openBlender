# 화면 구성 살펴보기

처음 블렌더를 켜면 버튼과 창이 많아서 막막하게 느껴져요. 하지만 처음에 알아야 할 영역은 네 군데뿐이에요.

## 처음 보이는 네 영역

기본 시작 화면(General)은 이렇게 나뉘어 있어요.

| 위치 | 이름 | 하는 일 |
|---|---|---|
| 가운데 큰 영역 | 3D 뷰포트 | 장면을 보고 물체를 만지는 작업대 |
| 오른쪽 위 | 아웃라이너 | 장면 안의 물체 목록 (폴더처럼 정리돼요) |
| 오른쪽 아래 | 프로퍼티 | 선택한 물체나 렌더의 설정 창 |
| 아래쪽 | 타임라인 | 애니메이션 시간 축 |

처음 열리는 장면에는 **큐브, 카메라, 조명**이 하나씩 들어 있어요. 이 셋이 3D 장면의 기본 세트예요.

## 맨 위의 작업 공간 탭

화면 맨 위에는 **Layout, Modeling, Sculpting, UV Editing, Texture Paint, Shading, Animation, Rendering, Compositing, Geometry Nodes, Scripting** 탭이 있어요. 이걸 *작업 공간*(Workspace)이라고 해요. 같은 장면을 하는 일에 맞게 창 배치만 바꿔 주는 거라서, 탭을 눌러도 작업이 사라지지 않아요.

- 모양을 만들 때는 **Modeling**
- 색과 질감을 만질 때는 **Shading**
- 움직임을 만들 때는 **Animation**

## 영역 다루기

- **크기 조절**: 영역 사이의 경계선을 끌어요.
- **영역 종류 바꾸기**: 영역 왼쪽 위의 에디터 타입 메뉴를 눌러서 다른 에디터로 바꿀 수 있어요. 타임라인 자리를 Graph Editor로 바꾸는 식이에요.
- **도구 모음 / 사이드바**: 3D 뷰포트에서 <kbd>T</kbd>를 누르면 왼쪽 도구 모음이, <kbd>N</kbd>을 누르면 오른쪽 사이드바가 열리고 닫혀요. 사이드바에는 선택한 물체의 위치, 회전, 크기 값이 나와요.

::: tip 가장 중요한 규칙
단축키는 **마우스 커서가 올라가 있는 영역**에서 동작해요. 키를 눌렀는데 아무 일도 안 일어나거나 엉뚱한 일이 생기면, 커서가 다른 영역에 있는지 먼저 확인해 보세요.
:::
