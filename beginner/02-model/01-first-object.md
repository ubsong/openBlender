# 첫 오브젝트 만들고 움직이기

블렌더에서 눈에 보이는 물체 하나하나를 **오브젝트**라고 불러요. 이 글에서는 오브젝트를 만들고, 옮기고, 돌리고, 키우는 가장 기본 동작을 익혀요.

## 오브젝트 추가하기

3D 뷰포트에서 <kbd>Shift</kbd> + <kbd>A</kbd>를 눌러 **Mesh** 메뉴에서 원하는 모양을 골라요. 원기둥(Cylinder), 구(UV Sphere), 원환체(Torus) 같은 기본 모양이 있어요.

새로 추가한 물체는 *3D 커서*가 있는 자리에 생겨요. 처음에는 장면 한가운데예요.

### 방금 만든 모양 다듬기

물체를 만든 직후 3D 뷰포트 왼쪽 아래에 **Add ...** 패널이 작게 접혀 있어요. 열어 보면 크기나 조각 수(Segments) 같은 값을 바로 바꿀 수 있어요. 다른 작업을 하면 이 패널은 사라지니 **만든 직후에** 조절하세요.

## 이동, 회전, 크기: G, R, S

물체를 선택하고 아래 키를 누른 뒤 마우스를 움직여요.

| 키 | 동작 | 영어 |
|---|---|---|
| <kbd>G</kbd> | 이동 | Grab |
| <kbd>R</kbd> | 회전 | Rotate |
| <kbd>S</kbd> | 크기 | Scale |

- **확정**: 왼쪽 클릭 또는 <kbd>Enter</kbd>
- **취소**: 오른쪽 클릭 또는 <kbd>Esc</kbd>

### 축을 정해서 움직이기

키를 누른 뒤 <kbd>X</kbd>, <kbd>Y</kbd>, <kbd>Z</kbd>를 누르면 그 방향으로만 움직여요. 거기에 숫자를 입력하면 정확한 값이 돼요.

예를 들어 <kbd>G</kbd> → <kbd>Z</kbd> → `2` → <kbd>Enter</kbd>를 차례로 누르면 물체가 위로 2만큼 올라가요.

## 복제와 삭제

- <kbd>Shift</kbd> + <kbd>D</kbd>: 복제 (복제 직후 이동 상태가 되니 클릭으로 확정하세요)
- <kbd>X</kbd>: 삭제

## 부드럽게 보이기

둥근 물체인데 면이 각져 보인다면 <kbd>Object</kbd> 메뉴의 **Shade Smooth**를 써 보세요. 모양은 그대로 두고 표면 음영만 부드럽게 만들어 줘요.

::: info 버전에 따라 달라지는 부분
자동 스무스(Auto Smooth) 관련 메뉴와 방식은 블렌더 버전에 따라 바뀐 적이 있어요. 오래된 튜토리얼에서 보던 메뉴가 안 보여도 당황하지 마세요. 여기서는 가장 기본인 Shade Smooth만 쓸게요.
:::
