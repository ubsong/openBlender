# 편집 모드로 모양 만들기

오브젝트를 선택하고 <kbd>Tab</kbd>을 누르면 **편집 모드**(Edit Mode)로 들어가요. 물체를 이루는 점, 선, 면을 직접 만지는 모드예요. 다시 <kbd>Tab</kbd>을 누르면 오브젝트 모드로 돌아와요.

## 점, 모서리, 면

3D 모델은 아래 세 요소로 이루어져 있어요.

| 키 | 선택 대상 | 영어 |
|---|---|---|
| <kbd>1</kbd> | 점 | Vertex |
| <kbd>2</kbd> | 모서리 | Edge |
| <kbd>3</kbd> | 면 | Face |

편집 모드에서 키보드 윗줄의 <kbd>1</kbd>, <kbd>2</kbd>, <kbd>3</kbd>을 눌러 선택 대상을 바꿀 수 있어요. 이동, 회전, 크기 조절(<kbd>G</kbd>, <kbd>R</kbd>, <kbd>S</kbd>)은 오브젝트 모드와 똑같이 쓰면 돼요.

## 자주 쓰는 편집 도구

| 키 | 도구 | 하는 일 |
|---|---|---|
| <kbd>E</kbd> | 돌출 (Extrude) | 선택한 면을 밀어서 새 면을 만들어요 |
| <kbd>I</kbd> | 안쪽으로 (Inset) | 면 안쪽에 작은 면을 하나 더 만들어요 |
| <kbd>Ctrl</kbd> + <kbd>B</kbd> | 모서리 깎기 (Bevel) | 날카로운 모서리를 둥글게 해요 |
| <kbd>Ctrl</kbd> + <kbd>R</kbd> | 루프 컷 (Loop Cut) | 물체를 둘러서 선을 한 줄 추가해요 |
| <kbd>M</kbd> | 합치기 (Merge) | 선택한 점들을 하나로 합쳐요 |
| <kbd>X</kbd> | 삭제 | 선택 대상을 지워요 |

## 따라 해 보기: 컵 만들기

1. <kbd>Shift</kbd> + <kbd>A</kbd> → **Mesh** → **Cylinder**로 원기둥을 만들어요.
2. <kbd>Tab</kbd>으로 편집 모드에 들어가 <kbd>3</kbd>(면 선택)을 누르고, 원기둥의 **윗면**을 클릭해요.
3. <kbd>I</kbd>를 누르고 마우스를 안쪽으로 움직여 가장자리를 남기고 클릭해요.
4. <kbd>E</kbd>를 누르고 <kbd>Z</kbd>를 눌러 아래로 내린 다음 클릭하면 속이 파여서 컵 모양이 돼요.
5. <kbd>Tab</kbd>으로 나와서 <kbd>Object</kbd> 메뉴의 **Shade Smooth**를 적용해요.

::: tip 한 단계 더
컵 옆에 **Torus**(원환체)를 만들어서 <kbd>S</kbd>로 납작하게 줄이고 <kbd>G</kbd>로 컵 옆에 붙이면 손잡이가 돼요. 손잡이가 컵과 만나는 부분이 어색하면 <kbd>Ctrl</kbd> + <kbd>R</kbd>로 선을 더해서 다듬어 보세요.
:::

## 더 부드럽게 만들고 싶다면: 서브디비전 서피스

오브젝트 모드에서 <kbd>Ctrl</kbd> + <kbd>1</kbd>을 누르면 **Subdivision Surface** 모디파이어가 추가돼요. 면을 잘게 나눠서 표면을 둥글게 만들어 주는 기능이에요. <kbd>Ctrl</kbd> + <kbd>2</kbd>, <kbd>3</kbd>은 더 촘촘하게 나눠요.

다만 너무 둥글어져서 모양이 뭉개질 수 있어요. 각을 살리고 싶은 모서리 근처에 루프 컷으로 선을 한 줄 더 넣으면 그 부분이 단단하게 유지돼요.

모양을 만들었다면 이제 색을 입힐 차례예요. [재질로 색과 질감 주기](/beginner/03-look/01-materials)로 이어가요.
